# Mini Projects🚀

A curated collection of frontend projects developed to strengthen practical skills in **HTML, CSS, and JavaScript**. Each project focuses on implementing core web development concepts through functional, responsive, and interactive applications.

## Projects📂

| Project                 | Description                                                                                     | Technologies               |
| ----------------------- | ----------------------------------------------------------------------------------------------- | -------------------------- |
| **Expense Tracker**     | Track, manage, and organize personal expenses through an interactive interface.                 | HTML, CSS, JavaScript      |
| **Todo – LocalStorage** | Task management application with persistent data storage using the browser's LocalStorage API.  | HTML, CSS, JavaScript      |
| **Weather App**         | Fetches and displays weather information using an external weather API.                         | HTML, CSS, JavaScript, API |
| **Weather Dashboard**   | Extended weather application providing a structured dashboard for weather information.          | HTML, CSS, JavaScript, API |
| **E-Commerce**          | Frontend e-commerce application demonstrating product interfaces and interactive functionality. | HTML, CSS, JavaScript      |
| **Quiz App**            | Interactive quiz application with dynamic questions, user interaction, and score tracking.      | HTML, CSS, JavaScript      |

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Khushali-Alt/Mini_Projects.git
```

### Navigate to the repository

```bash
cd Mini_Projects
```

### Run a project

Navigate to the required project directory:

```bash
cd _04_weather_dashboard
```

Open `index.html` in a browser, or use a local development server such as the **VS Code Live Server extension**.
